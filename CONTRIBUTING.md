# Contribuir

Gracias por querer contribuir a Claude Code Rust.

## Cómo colaborar

1. Crea una rama nueva.
2. Realiza cambios pequeños y claros.
3. Ejecuta formato y validación.
4. Abre un pull request con una descripción clara.

## Comandos recomendados

```bash
cargo fmt
cargo check
cargo test
```

## Traducciones

Para mantener el proyecto en español:

- Traduce textos visibles para usuarios finales.
- No traduzcas nombres internos de campos, estructuras, funciones, comandos técnicos o claves de configuración.
- Mantén ejemplos de código funcionando.

## Estilo

- Código idiomático de Rust.
- Mensajes claros.
- Documentación simple para usuarios finales.
