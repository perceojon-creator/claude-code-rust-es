# Código de conducta

Este proyecto busca mantener una comunidad respetuosa, segura e inclusiva.

## Comportamiento esperado

- Tratar a todas las personas con respeto.
- Aceptar comentarios constructivos.
- Ayudar a otros usuarios y colaboradores.
- Mantener discusiones enfocadas en el proyecto.

## Comportamiento no aceptado

- Insultos, acoso o discriminación.
- Publicación de información privada.
- Spam o contenido malicioso.
- Comentarios que impidan colaborar de forma sana.

## Reportes

Si encuentras un problema de conducta, abre un issue o contacta a los mantenedores del repositorio.
